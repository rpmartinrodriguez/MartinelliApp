Respaldo de Martinelli Autos

Archivos guardados en Windows · Solo administración

Carpeta local de destino

Buscando carpeta autorizada...

Dentro de la carpeta que elijas se crea Martinelli Autos / Respaldos. El navegador puede volver a pedir permiso tras reiniciar.

Descargas manuales

El ZIP incluye las nueve colecciones actuales de Firebase, un JSON recuperable y la caja en Excel/CSV. Cada descarga lee la información actual de Firebase.

Copias automáticas mientras la aplicación esté abierta

El respaldo automático necesita la aplicación abierta, Internet y una carpeta con permiso vigente. No funciona con Chrome/Edge cerrados o Windows apagado.

Atención: los respaldos incluyen información personal y financiera. No incluyen las contraseñas de Firebase Authentication. Conservá los archivos en una carpeta privada y protegida.

Recuperación de datos

Comparar y restaurar únicamente registros faltantes

Elegí un ZIP de respaldo completo o un Excel/CSV de caja generado por esta aplicación. No se importan Excel de terceros ni registros editados manualmente.
